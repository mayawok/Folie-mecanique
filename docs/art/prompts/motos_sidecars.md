# Lot 12 — Motos et side-cars (08/11/2026, DEC-138)

Méthode : **pièces séparées sur une seule planche** (comme le Berliet), fond magenta, même échelle pour toutes les pièces d'une planche.
Les roues sont à part pour tourner en jeu. La moto se retourne par miroir. Le side-car a deux faces : la nacelle est dessinée
**des deux côtés sur la même planche** (mêmes proportions garanties) ; Claude la pose devant la moto (side-car qui va vers la droite,
nacelle côté spectateur) ou derrière (side-car qui va vers la gauche, nacelle cachée par la moto).

Joindre à chaque demande l'image de style : `docs/art/vehicules/berliet_gdr/planches/cabine.png`.
Une demande = une image. Chaque prompt ci-dessous est complet (à copier tel quel).
